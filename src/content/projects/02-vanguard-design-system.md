### Executive Overview

Vanguard is an enterprise design system crafted to serve 14 distinct product teams across web, mobile, and internal administrative tooling. It solves the fragmentation of disparate UI patterns through a single tokenized contract synchronized directly with Figma Variables.

### Key Architectural Highlights

- **Token Pipeline Automation**: Created a CI/CD pipeline that transforms design tokens defined in Figma into CSS Custom Properties, Tailwind Presets, iOS Swift tokens, and Android XML assets.
- **Headless Accessible Primitives**: Built upon unstyled accessible foundations with complete keyboard navigation patterns, screen-reader focus traps, and automated a11y testing.
- **Zero-Runtime Styling Mode**: Provided CSS module and Tailwind plug-in modes that eliminate client-side CSS-in-JS runtime overhead completely.

### Measurable Engineering Impact

- Shipped over 65 production-grade components used by 180+ developers daily.
- Reduced overall frontend bundle weight across core enterprise applications by 35%.
